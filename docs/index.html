Clone from here

    
The app's form, in your browser. Paste repos or an org, pick the options, then copy one command or a script that clones them all with plain git. Browsers may not run git on your computer, so the last step is one paste into a terminal.

01Cloning

          
    
            
  • Many at onceFour in parallel by default, anything from 1 to 16. The rest wait their turn in a queue.
    • 
            
  • Paste a list in any shapeOne per line, or separated by commas, semicolons or spaces. A whole block from a spreadsheet works.
    • 
            
  • Duplicates collapseThe same repo twice is cloned once, whatever the case or the trailing .git; it tells you how many were dropped.
    • 
            
  • No folder fightsTwo repos called api from different owners land in api and api-2.
    • 
            
  • Branch of your choiceSet one for the whole batch, or let each browser URL bring its own /tree/<branch>.
    • 
            
  • Shallow clonesOne toggle for --depth 1 --single-branch, when you only need the latest code.
    • 
            
  • SubmodulesPulled in with the repo when you turn them on; shallow too, if shallow is on.
    • 
            
  • When the folder existsSkip it, clone beside it as repo-2, or overwrite it — after a confirmation, and never a drive root or the folder you are standing in.
    • 
            
  • Missing folders are madeThe destination and its parents are created; ~ expands to your home folder.
    • 
            
  • Windows-proof namesFolder names are cleaned of : ? *, trailing dots and device names like nul; long paths are switched on.
    • 
          

        


        

          
02What you can paste

          
    
            
  • owner/repoShorthand for GitHub.
    • 
            
  • Any HTTPS hostGitHub, GitLab (with subgroups and /-/tree/ links), Bitbucket, Azure DevOps, Gitea, your own server.
    • 
            
  • Browser links/tree/, /blob/, ?query and #fragment are trimmed; a branch in the link is used.
    • 
            
  • SSHgit@host:owner/repo and ssh://git@host:2222/…, with your own keys.
    • 
            
  • Local reposA path on disk or a file:// URL.
    • 
            
  • Organisations and usersgithub.com/your-org opens a list of its repos to pick from.
    • 
            
  • Bad lines do not stop the restAnything unreadable is listed with the reason; everything else still clones.
    • 
          

        


        

          
03Picking from an org

          
    
            
  • Every repo, every pageOrg or user, public and — with a token that can see them — private. One API call covers a hundred repos.
    • 
            
  • The details beside eachLanguage, stars, size on GitHub and how long ago it was last pushed.
    • 
            
  • A detail panelDescription, forks, open issues, license, default branch and topics for the highlighted repo.
    • 
            
  • Sensible ticksEverything starts ticked except forks and archived repos; a ticks all or none.
    • 
            
  • Know what you are pullingThe header adds up the size of what is ticked.
    • 
            
  • Your own repos in one keyProfile (F3) shows the account behind your token; enter lists its repos.
    • 
          

        


        

          
04Tokens and safety

          
    
            
  • Only when neededPublic repos need nothing. Private ones take a PAT from the form, --token, or GITCLONER_PAT, GITHUB_TOKEN, GH_TOKEN, GITLAB_TOKEN.
    • 
            
  • Never on the command lineThe token reaches git through GIT_ASKPASS — gitcloner answers git's prompt itself — so it is not in ps, Task Manager or your shell history.
    • 
            
  • Never on diskNot in .git/config, not in the settings file. A token typed into a URL is pulled out before git sees it.
    • 
            
  • Never in a logAnywhere it could be printed it becomes ***. The token field is masked until you press ctrl+t.
    • 
            
  • The right usernamex-access-token for GitHub, oauth2 for GitLab, x-token-auth for Bitbucket — or your own.
    • 
            
  • Never hangsNo password prompts, no credential-manager pop-ups, SSH in batch mode: a missing credential fails at once with a clear reason.
    • 
          

        


        

          
05While it runs

          
    
            
  • Live progressPer repo: the phase, a percentage, how much has arrived and how fast. An overall bar on top.
    • 
            
  • Change the pace live+ and - add or remove parallel clones mid-batch.
    • 
            
  • Cancel cleanlyc for one, C for all. The whole git process tree goes, helpers included.
    • 
            
  • Nothing half-writtenA failed or cancelled clone removes its folder — only if gitcloner created it.
    • 
            
  • Errors in plain wordsPAT rejected, repo not found, needs a token, network or proxy trouble, certificate rejected, branch missing, path too long, disk full, transfer broke.
    • 
            
  • Retry without retypingr for the selected one, R for everything that failed.
    • 
            
  • A summary at the endHow many cloned, failed or were skipped, how long it took, and why each failure failed. o opens the folder.
    • 
            
  • ScriptableThe exit code is 1 if anything failed, so it fits in a script.
    •

  • A start screenA pixel planet turning under a short menu. URLs on the command line skip it.
    • 
            
  • Six themesOcean, mint, ember, rose, mono, and paper for light terminals.
    • 
            
  • Animated, or stillMoving bars, shimmer and cascading lists — or all of it frozen, in one setting.

Command line

      
Everything the form does, from the shell. Nothing is cloned until you press ctrl+s.

      
$ gitcloner owner/repo https://github.com/owner/other
$ gitcloner "a/b, c/d; e/f"          # one argument can hold a list
$ gitcloner https://github.com/myorg  # pick from its repos
$ gitcloner owner/repo -d ~/src -b dev --shallow
$ GITHUB_TOKEN=ghp_… gitcloner team/private

    

    

      
-d, --dest <DIR>where to clone into — default: the current folder

      
-b, --branch <NAME>branch to check out

      
-t, --token <PAT>personal access token, for private repos

      
-u, --user <NAME>username for the token — default: right one per host

      
--shallow--depth 1 --single-branch

      
--updateupdate gitcloner to the latest release

      
-h, --helpevery option

      
-V, --versionthe version, and who made it

tab next field
ctrl+s start
ctrl+t show token
ctrl+u clear field

space tick
a all / none
enter clone ticked
esc back

c / C cancel one / all
r / R retry one / all
+ / - more / fewer at once
o open folder, when done
