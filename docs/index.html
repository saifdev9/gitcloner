Why it is pleasant

    
Small things, done carefully.

    

      
Your token never touches the command line, .git/config, or the log.
It reaches git through GIT_ASKPASS — this very binary answers git's credential prompt — and is replaced with *** anywhere it might be printed.

      
Pick from an org
Paste github.com/your-org and tick the repos you want, with stars, size and last push beside each.

      
Any URL shape
Browser links, owner/repo, SSH, GitLab subgroups, Azure, local paths.

      
Nothing half-written
A failed or cancelled clone takes its folder with it.

      
Themes and settings
F2 — six themes, animations, a summary popup.
